# Python Story Generation Application

## About the Project

The **Python Story Generation Application** is a simple Python project that generates random stories based on user-provided inputs. Users can customize their stories by entering a topic, character name, place, genre, and story length.

The application uses predefined story templates and Python's `random` module to select and display a story that matches the user's preferences.

## Features

- **User Input:** Enter a story topic, main character, and place.
- **Multiple Genres:** Choose Horror, Fantasy, Romance, or Adventure.
- **Story Length Options:** Generate short, medium, or long stories.
- **Random Story Selection:** Get a randomly selected story from the available templates.
- **Interactive Console:** Enter details and view the generated story directly in the terminal.
- **Default Genre Handling:** If an unsupported genre is entered, the application uses Adventure as the default genre.

## Technologies Used

- Python
- Random Module
- Lists and Dictionaries
- Conditional Statements
- User Input and Output
- F-Strings

## How It Works

1. The user enters a topic, character name, and place.
2. The user selects a genre and story length.
3. The program identifies the appropriate collection of story templates.
4. Python's `random` module selects a story.
5. The generated story is displayed in the terminal.

## Supported Genres

| Genre | Description |
|---|---|
| Horror | Mystery and suspense stories |
| Fantasy | Magical worlds and adventures |

